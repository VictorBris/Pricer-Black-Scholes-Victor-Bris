Projet de Mathématiques appliquées – M2 Gestion de Portefeuille, IAE Paris-Est

## Objectif
Calculer le prix d'options européennes (call et put) avec le modèle de Black-Scholes,
ainsi que les principaux Greeks (Delta, Gamma, Vega, Theta, Rho).
